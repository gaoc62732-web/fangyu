# 方舆旅游手册

方舆是一款记录旅行足迹的手册。它将地区到访、景点、交通项目和旅行成就整理在地图与清单中，帮助你回看去过的地方、保存个人备注，并按自己的兴趣规划下一次旅行。

当前版本：**0.7.1**。

## 主要功能

- 中国省、市、县地图，世界总览和多国专题地图；支持地区搜索、地图筛选和图片导出。
- 地区到访状态、景点与交通项目标记、个人名称和备注，以及个人新增项目。
- 已到访机场、世界遗产等专题图层，旅行成就和卯分统计。
- JSON 备份与恢复、Excel 导入导出，以及名称清单和轨迹／GPS 文件导入。
- 自定义 OSM Liberty 底图、地图配色和深色界面。

## 记录与存储

本地模式将记录保存在当前浏览器中；服务端模式支持账号和数据库存储。两种模式可以通过 JSON 备份转移记录。个人记录不包含在公共数据包中。

## 地图与公共数据

方舆使用开放地理数据与公开项目资料。地图用于旅行记录参考；不同地区的资料完整度、时间和精度可能不同。数据来源与许可见[数据说明](docs/data-notices.md)。
