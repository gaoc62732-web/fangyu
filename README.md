# 方舆旅游手册

方舆用于记录地区到访、景点与交通项目、旅行成就和卯分。当前为 **0.6.7-dev 架构重构版**，使用 Vue 3 + TypeScript 前端、NestJS 后端、PostgreSQL/PostGIS 数据库，统一由 pnpm workspace 管理。

本轮地图、列表、成就与点卯界面的更新详见 [v0.6.7-dev 修订说明](docs/revision-notes-v0.6.7-dev-2026-09-30.md)。

本轮已经迁移现有功能的源码与目录数据。2026-09-29 的最小检查通过了类型检查、目录引用检查、前后端生产构建及前端本地演示模式的关键操作，发现 5 项待处理的功能差异；详见 [检查报告](docs/minimal-verification-2026-09-29.md)。**数据库与服务端联调、完整功能回归仍未完成，不能视为已验证的上线版本**。详细设计见 [重构方案](REFACTOR_PLAN.md)，第一轮实现边界见 [迁移记录](docs/first-round-migration.md)。

## 测试人员：一键安装

1. 将整个项目解压到可写目录，保留目录结构。
2. 在 Windows 中双击 [安装依赖.cmd](安装依赖.cmd)，等待出现安装完成提示。首次安装需要网络。
3. 后续需要体验界面时，双击 [启动前端.cmd](启动前端.cmd)，保持命令窗口开启，在浏览器打开窗口中显示的网址，通常为 http://localhost:5173 。

安装器会检查 Node.js（至少 22.12，推荐 24 LTS），缺少时下载官方 Node.js 24 LTS 到项目内的 .tools 并校验 SHA-256；不会要求全局安装 pnpm。它使用锁定的 pnpm 10.15.0 安装依赖、补齐前后端 .env 文件并生成随机认证密钥。再次运行会保留已有配置值。安装失败时窗口保留错误信息，可修复网络后重试。

macOS/Linux 先安装 Node.js 24 LTS，再在项目目录执行：

```sh
sh install.sh
npm run dev:web
```

安装脚本只安装本项目的 Node.js 依赖，**不会安装 Docker、启动服务或初始化数据库**。如果 Windows 使用安装器下载的本地 Node，请优先使用双击入口；开发者在命令行操作前需将 .tools/runtime-path.txt 指定的目录加入当前 PATH。

## 两种记录存储方式

| 模式             | 使用方式                               | 记录位置                   |
| ---------------- | -------------------------------------- | -------------------------- |
| 本地演示（默认） | 安装依赖后启动前端即可                 | 当前浏览器的 IndexedDB     |
| 服务端           | 配置数据库、初始化账号，前后端同时运行 | PostgreSQL，按登录用户隔离 |

服务端配置步骤见 [开发与数据库初始化](docs/first-round-migration.md#服务端初始化)。浏览器本地模式和服务端模式不自动同步；可使用新版 JSON 备份转移记录。浏览器清理数据或切换访问地址会影响本地记录，重要记录应自行导出备份。

## 当前功能

- 中国省、市、县地图，世界地图，日本与韩国专题；地区选择、搜索、要素筛选、已有地点坐标显示及 PNG 导出。
- 六级到访状态、项目与组成项目标记、个人名称和备注、个人新增项目、关联地区状态、撤销和命名存档。
- 数量成就、政区与历史专题、趣味及国际成就；卯分计算、分省排序和 CSV 导出。
- 新版 JSON 完整备份与恢复；新版 Excel 双向导入导出；文本/DOCX 名称清单；机场代码和别名匹配。
- Railtrack 历史记录、KML、OSM XML/PBF 和照片 GPS 导入；预览、歧义选择、自动备份及核对报告。
- 多套地图配色、自定义颜色与深色界面。

导入文件在浏览器解析；服务端模式仅保存确认后的结构化记录和存档，不接收原始照片、工作簿或轨迹文件。部分大型文件解析仍在主线程，实际性能有待后续验收。

## 格式变更与资料范围

本次开发阶段重构不兼容旧版单文件 HTML、旧单元格 JSON、旧 Excel 模板和旧 localStorage 数据。Excel 采用“地区记录”“项目记录”两张结构化表，以实体 ID 关联；JSON 是完整备份，Excel 是记录合并工具。旧版代码可在 Git 提交 3decac6 查阅；工作区内旧页面与兼容工具已移除，原来的 GitHub Pages 发布方式不再适用于此结构。

数据是原目录的结构化迁移，未重新核定所有地点、政区与边界。底图只供旅行记录参考；韩国目录仍为已有 16 地区口径，部分铁路和地点清单不完整。完整来源、许可标注与统计口径见 [数据说明](docs/data-sources.md)。地图地点编辑和铁路网络分析属于后续工作，本轮没有创建空接口。
