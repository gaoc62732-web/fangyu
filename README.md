# 方舆旅游手册地图（空白审核版）

当前应用版本：**v0.1.0**。版本变化见 [CHANGELOG.md](CHANGELOG.md)；仓库根目录的 [VERSION](VERSION) 保存当前版本号。

这是可离线打开的**空白审核版本**，包含中国政区与世界国家和地区地图、旅游要素名录、记录导入、趣味成就及手册双向转换工具。仓库只收录已清空个人到访数据的审核材料，不收录原始手册、行程文件和个人记录。

下载或克隆仓库后，用 Edge 或 Chrome 打开 **[先打开这里.html](先打开这里.html)**，按页面说明进入地图。地图、照片定位导入和 Excel→地图助手都可离线在浏览器中使用，无需安装 Python、Node 或 GIS 软件。照片助手读取照片内嵌 GPS，先预览命中政区，再由使用者确认写入；不含 GPS 的照片不会自动定位。Excel→地图助手见 [工具/方舆Excel导入助手_兼容版.html](工具/方舆Excel导入助手_兼容版.html)。地图记录→Excel 的 Python 工具需要另装 `openpyxl`，用法见 [手册兼容测试说明.md](手册兼容测试说明.md)。

首次打开时所有到访状态均为空。记录保存在当前浏览器的本地存储中；请使用页面内的存档／导出功能自行备份。浏览器数据清理、无痕模式或更换设备不会自动同步记录。

趣味成就规则及 2025 百强榜来源见 [趣味成就说明.md](趣味成就说明.md)。审核范围和反馈方式见 [功能与检查说明.html](功能与检查说明.html)。[导入测试](导入测试) 中的车站清单仅供测试，不代表个人行程。文件 SHA-256 见 [文件校验清单.json](文件校验清单.json)。
