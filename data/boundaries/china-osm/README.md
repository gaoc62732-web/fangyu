# 中国行政区边界数据

本数据集包含中国国界及省、市、县级行政区的 OSM 边界快照，用于方舆旅游手册的地图展示。地区标识与方舆公共目录对应。

数据集包含行政区多边形、国界线、来源与覆盖清单，以及藏南、阿克赛钦和阿鲁纳恰尔邦的独立参考文件。参考文件不属于当前行政区地图图层。

快照日期：2026-10-03 至 2026-10-04。不同地区的数据完整度与精度可能不同，本数据集不用于法律或测绘边界认定。
