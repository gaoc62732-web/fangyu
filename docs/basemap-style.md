# 底图显示规则

样式文件为 `apps/web/src/features/maps/styles/osm-liberty.json`，由 MapLibre 加载，使用 OpenFreeMap 的 OpenMapTiles 矢量瓦片。可在 Maputnik 中继续编辑；颜色与标签调整不需要重新下载边界或生成瓦片。

本版参考 STELE 的实际地图与公开 CN7 HC 样式，使用其米灰陆地、浅蓝水系和分级道路配色。STELE 的自定义瓦片字段与 OpenMapTiles 不同，因此采用适配当前数据源的显示规则。城市名称保持关闭，后续由项目独立实现自定义城市标识。

## 色块与线条

| 元素                                      | 当前显示                                                       |
| ----------------------------------------- | -------------------------------------------------------------- |
| 陆地背景                                  | z9 及以下 `#F3F1ED`，z10 起 `#EBE8DE`；移除地形晕染源          |
| 水体、河流                                | `#AACEFD`；河流/运河 z8 起，小水道 z12 起                      |
| 公园                                      | z8 起浅绿 `#d8e8c8`；取消醒目的描边                            |
| 草地、沙地、湿地                          | z10 / z10 / z13 起显示，降低不透明度，湿地使用纯色             |
| 居住区                                    | z10 起灰色 `#e2e2e2`；修正原有 maxzoom8 与颜色 z9 起变化的冲突 |
| 商业、工业、交通用地                      | 分别使用淡米黄、淡紫、淡灰紫；z12 / z11 / z12 起               |
| 学校、医院、运动场                        | 淡黄、淡粉、淡绿；z12 / z13 / z14 起                           |
| 建筑                                      | z13 起平面淡棕灰轮廓，随放大提高不透明度；取消 3D 拉伸         |
| 高速 / 主干道 / 次干道 / 三四级及普通道路 | 橙黄 / 淡黄 / 浅黄绿 / 白色；桥梁与隧道同步分级                |
| 铁路                                      | z10 起灰色；城市轨道 z12 起更淡，z15 起可见铁路横纹            |
| 底图国界                                  | 全球删除 admin_level2 图层，不显示争议/普通国界                |
| 底图省界                                  | 境外保留淡灰虚线；中国范围由项目行政边界接管                   |

项目自己的行政区面、区界线和 `border-line` 属于独立叠加层。删除底图国界不会删除这些数据；后续国界数据调整应在叠加层处理。

## 标签与普通点位

普通名称默认直接取 OSM 的 `name`，保留当地名称，不优先中文翻译。仅中国地图在组合样式时依次取 `name:zh-Hans`、`name:zh`、`name`；中文来自 OSM 原有的名称标签，没有引入翻译服务。字体使用 Noto Sans Regular。标签启用避让，不强制重叠；道路、水系采用沿线排布并限制重复间距。

河流与运河名字号为 z10 时 10px、z13 起 12px（原为 11–14px）。湖泊及内陆水面名字号为 z9 时 10px、z15 时 11px（原为 11–13px）。

| 元素                              |                               最低缩放级别 |
| --------------------------------- | -----------------------------------------: |
| 国名、洲名、城市及其他 place 名称 |                                   全部关闭 |
| 海洋、海域、海湾、海峡名称        | 全部关闭；水体标签仅允许 lake / river 类别 |
| 湖泊与内陆水面名                  |                         z9；兼容点与线要素 |
| 河流、运河名                      |                                        z10 |
| 高速公路名                        |                                        z11 |
| 主干道名                          |                                        z12 |
| 次干道、三四级道路名              |                                        z13 |
| 普通道路名                        |                                        z15 |
| 服务道路、步道、田间道路名        |          z16，当前项目最大 z15，因而不出现 |
| 国际/区域机场                     |                                        z12 |
| 铁路车站、渡口                    |                    z14；仅保留 rank≤5 的点 |
| 公交站                            |              z16，当前最大 z15，因而不出现 |
| 学校、大学、医院、公园            |                    z15；仅保留 rank≤4 的点 |
| 餐饮、商店等普通商业 POI          |                                       关闭 |

这里的缩放级别是样式门槛；实际出现还受瓦片中是否提供该对象、名称、排名和标签避让影响。底图 POI 是公共地理参考，项目自己的遗产点、旅行记录与已到访标识由原有图层管理。

## 验证

MapLibre 样式校验覆盖全部地图范围；浏览器验证真实矢量瓦片、中文字体、PMTiles 边界、开关与状态保持。视觉样例保存于 `data/generated/stele-style-checks/`，常规地图回归截图在 `data/generated/liberty-map-checks/`。参考 STELE 的配色不意味着两个来源的路网、土地利用或坐标完全相同。
