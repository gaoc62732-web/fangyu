# 中国行政边界整理记录（2026-10-06）

按用户逐项确认的画法整理本地边界。初次整理在暂停网络获取后完成；随后用户允许恢复网络，要求细化海岸、只保留始终露出水面的陆地，并在前端页面验收。本文保留未完成事项，不能将成果解释为已经完成全国官方边界认证。

## 方法与来源

- 汉南、文登由完整 OSM 街道／乡镇面拼接，归属以政府说明核对，不用天地图较粗的区面整体替换。
- 已确认的中印、中不地段、唐古拉和黑瞎子岛，以天地图公开区划几何核验并修正指定范围，范围外保留 OSM 细节。OSM claimed_by 仅用于定位，不能决定合并。
- 三沙和指定离岛使用已取得的 OSM 闭合海岸，只保留实际陆地，不创建礁滩符号。中沙已取得的实际陆地纳入西沙；南沙按地理群岛而非控制方收集。
- 天地图公开数据中的 156990000 是独立的十段 MultiLineString，作为 border 要素保存，不参与填色或县级空间命中。
- 海域裁剪采用 OSM `natural=coastline` 原始节点，按共享节点与岸线方向构建连续大陆面及闭合岛屿面。源几何不简化、不平滑、不用参考海岸代替；旧参考海岸只留作对照。海水和潟湖面排除，内陆江河湖泊保留；不获取礁盘、潮间带和水下地形，不添加礁滩符号。
- 独立轮廓文件 `osm-land-outlines.geojson` 保存已取得的实际陆地外缘，排除大陆面构造所需的境外人工闭合线。原始查询框包含周边外国陆地，轮廓获取不等于行政归属确认；仅有归属证据的面进入中国行政几何。
- 最新授权要求先做普通海岸。珠江口、杭州湾等大型入海口保留已取得的 OSM 原始资料，特殊河口处理规则待后续讨论，本轮不新造闭口线或调整这些地段的归属。
- 粗线仅用于连续陆上国界及南海断续线；海岸和岛屿轮廓由省、市、县的普通边界层绘制。独立线的类型随源数据、简化图和矢量瓦片保留；屏幕及 Canvas／PNG 使用同一筛选规则。

天地图门户说明公开数据用于地图可视化，2025 年 9 月曾局部更新；它不能替代更高精度的勘界成果。本轮保存原始响应、解码结果、来源 URL 与 SHA-256。未把第三方数据的审图号目录名当作官方认定依据。

## 保留资料和离线流程

原 OSM 面保留于 data/boundaries/china-osm/，修改前几何保留于 data/boundaries/china-policy/references/。校订面、来源和覆写面随 research 数据包运输，不进入应用记录库。

Python 需 Shapely、pyproj，依赖见 scripts/requirements-china-gis.txt。以下命令均不访问网络：

```sh
python scripts/prepare-china-boundary-policy.py
python scripts/build-china-coastal-mask.py
python scripts/apply-china-boundary-policy.py
python scripts/apply-china-boundary-policy.py --apply
node scripts/verify-catalog.mjs
node scripts/prepare-web.mjs
```

先整理检查草稿，--apply 才写运行几何。重复应用同一版本会直接返回；源文件变更后须重新核对。缺少原始缓存时可读取 sources 中的已保存证据。以后 OSM 导入保留已发布校订面，新原始数据另存供复核。

更新海岸掩膜后，用 `python scripts/apply-china-boundary-policy.py --reclip --apply` 从 `references/pre-coastal-base.json` 重裁。该基线的 SHA-256 必须与最初审核记录一致；不得直接对已裁剪结果再次求交。上一版运行几何和海岸掩膜保存在 references 中，便于比较及恢复。

草稿已经完成审计时，可使用 `--reclip --publish-draft --apply` 发布同一草稿，命令会重新检查基线、证据、校订面、掩膜、草稿哈希、行数及失败记录。`audit-china-coastal-coverage.py` 只定位已取得陆地与行政面的缺口，不写行政归属；检查市级覆盖时纳入省直辖县。

中国矢量瓦片保留到 z12，最大层级保留源折点后作瓦片坐标量化（8192 extent，赤道约 1.2 米，沿中国海岸更小）。简化图／PNG 的几何简化容差从 0.00005 度降至 0.000002 度；运行源面和独立轮廓仍保留原节点。导出另有省、市、县分层文件，精度一致，省级 PNG 无需解析全部县级面。新瓦片使用版本文件名，避免 Windows 正在读取旧文件时替换失败，也避免前端读到上一版海岸。`verify-china-policy-assets.mjs` 除归属点位外，还比较实际瓦片节点与原始 OSM 岸线节点。

## 未完成事项

1. 全域大查询中部分超时，已由分片和缺口查询拼接连续大陆岸线及海南、台湾等轮廓，并补查澎湖、绿岛、台湾北部与浙江外围岛屿。共 19,315 条 OSM ways、1,100,579 个原始节点、13,025 个陆地面。未闭合的查询框边缘碎片不封口造岛；这些数量仍不能证明所有细小出水陆地和三沙岛屿均已齐全。旧参考海岸已退出运行掩膜。
2. 尚不能证明中沙所有实际陆地面齐全；没有完整海岸的礁滩不添加面或符号。后续需逐岛核验。
3. 阿克赛钦、沙克思干可与本地官方省／县可视化数据对照，但尚无更精确的完整境界线。未明确依据的部分保留原线，不把比例尺差异当作新增争议范围。
4. 全国省、市、县之间潜在归属争议未逐处调查完毕。甘蒙接界等仍需正式县级资料；新增冲突需先列出并咨询用户。
5. 官方可视化省、市、县并非完全同精度、同拓扑。审计中的父级范围例外保留记录，不能按邻近县猜归属。
6. 本地成果未发布为新快照；同步旧 runtime 包会恢复旧地图。新快照须重新打包并由用户决定是否发布。
