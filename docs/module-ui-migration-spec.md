# 模块界面迁移约定

确认日期：2026-10-06。点位页当前 UI 已基本认可，本轮不继续调整其地图、图标、资料栏或关联确认细节。

## 统一框架

- 沿用点位页的浅色背景、轻字重黑体、32px 标题、16px 正文与按钮、14px 辅助信息，以及柔和圆角、少量分隔线与较少阴影。
- 所有页面共用约 56px 的顶栏，四个主要入口为“区域点卯、点位点卯、成就、导入导出”。
- “记录（原要素列表）、卯分（原点卯计算器）、存档与外观、使用说明”收纳到“更多”。功能继续可用，不改变记录、计分或备份规则。
- 点位页移除临时返回原始页面按钮和独立顶栏，接入共同导航；地图仍占据顶栏以下的页面，不再叠加第二个顶栏。
- 成就、导入导出等非地图模块采用共同文字与控件规范，保留适合其任务的图鉴、表格和表单，不强行放入地图。

## 区域点卯

- 各国家／地区旅游手册合并为一个“区域点卯”模块，地图内选择探索范围；范围切换不等于合并不同国家的记录。
- 区域点卯仅保留行政区地图、区域状态修改、地区查找、下辖地区导航与统计。地点目录、世界遗产、球场、文保及个人地点操作统一进入点位点卯。
- 地图为主视图，右侧地区资料栏可以关闭和重开，左边缘可拖动调宽；状态控件留在资料栏顶部，正文独立滚动。
- 区域地图继续展示地区旅行状态配色并允许点击选区；不应用点位页的不可选择规则或浅色蒙版。
- 保留中国省市县导航和派生状态、法国分层与海外范围、其他国家的行政区分组，以及原有撤销行为。
- 原始国家路由与成就中的地区深链接继续兼容，跳转到统一模块时保留地区与来源查询参数。马新文旧集合入口跳转到其选定国家的区域页。
- 记录列表原有“定位地图”改为打开点位模块中对应地点及类别；有可用坐标时沿用明确定位操作的近景视野，无坐标时仍可查看资料。常规点位选择和类别切换的既定视野规则不变。
- 地图来源、地图图片导出及区域底图配置继续可用，收纳到地图工具，不加入点位记录偏好。
- 2026-10-06 补充确认：选择行政区后，约 650 毫秒平滑移动和缩放到区域占地图主要空间的视野。地图工具中的“选区自动缩放”默认开启并持久保存；关闭后，选择区域只更新高亮和资料，不改变地图中心与缩放，行政层级切换也不强制重置视野。手动定位和全图按钮仍按明确操作调整视野，简化地图采用同样规则。

## 本轮明确暂缓

使用者选择“本轮先迁移区域和共同框架，这些附加操作留到下一轮”。个人地点新增、地点名称与备注编辑、球场参观／现场观赛入口本轮不加入点位页。旧专题展示代码保留为迁移参考，数据与记录继续保留；记录页已有的操作仍可用。本轮区域页不继续挂载旧地点面板。

## 变更边界

本轮不改变点位存档兼容方案、关联询问策略、行政区计分、导入预览与应用确认、备份和存档行为。若迁移要求新增产品流程或改变这些规则，先提出具体问题并取得确认。
