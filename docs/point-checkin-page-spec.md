# 独立点位点卯页面约定

状态：第一版开发基线

本文固定当前讨论已经确定的产品行为。实现过程中如果需要改变本文列出的行为，或新增本文未覆盖的产品能力，先向使用者说明影响并取得确认。

## 页面定位

- 点位点卯作为独立于区域点卯的页面和入口存在。
- 页面始终以当前区域地图为主视图，沿用区域点卯的行政区地图、当前区域、地图中心、缩放与拖动；点位页中的行政区边界仅作展示，不支持区域点击与悬停选择。
- 点位是叠加在区域地图上的独立图层；点位图层可以按类别开关或切换，第一版先沿用现有圆点样式。
- 地图可自由缩放，点位随地图一起投影和聚合；探索范围切换、类别切换和资料栏开关不应重置地图中心或缩放。
- 页面首次打开时沿用当前区域点卯的行政区域和地图视野。当前视野没有可显示点位时，可以平滑缩放或移动到包含点位的视野。
- 一次只显示一个点位类别。类别通过页面上的选择控件切换；切换类别不改变地图视野。
- 点位密集时允许使用聚合数量或按缩放级别逐步展开；放大后显示单个点位。聚合行为不改变点位记录。

## 资料栏

- 点击点位后，在地图右侧打开固定资料栏。
- 资料栏是可关闭、可缩回的临时界面，不是页面永久嵌入内容。
- 收起资料栏后，地图扩展为主视图；重新打开资料栏时恢复当前点位详情，不改变地图中心和缩放。
- 资料栏上部固定显示当前点位的名称、当前类别、当前点卯状态和主要操作按钮。
- “点亮”按钮必须在简介内容滚动前即可看到；资料栏下部可以独立滚动显示图片、身份资料、简介和关联信息。
- 资料栏的具体字段、图片布局、色彩、字体和视觉细节可以继续调整，但不能改变上述层级和可操作性要求。

## 点位记录与区域记录

- 点位记录与行政区记录分别保存。
- 点亮点位后，可以询问是否一并点亮点位所在的行政区；行政区询问属于独立设置项。
- 行政区关联设置提供三种模式：每次询问、自动点亮、不联动行政区。
- 点亮点位时如果存在多个明确关联行政区，应列出这些行政区供选择；跨地区项目不能仅凭项目总名自动推断用户到访了所有地区。
- 确认行政区关联时，地图高亮待修改的行政区；确认或取消都不改变地图视野。

## 子项与总项目

- 总项目不保存独立的手动点卯状态。
- 总项目状态由子项记录自动计算：未选择子项为未点亮，选择部分子项为部分到访，全部可用子项点亮时为已全部到访。
- 点亮一个子项时，不自动点亮同一总项目中的其他子项。
- 点击总项目或进入总项目的组成地点操作时，可以选择实际去过的子项，也可以选择全部子项。
- “是否自动全部点亮／是否每次询问”属于设置项；默认保留每次询问。
- 子项不完整或官方组成点数据未收录完整时，页面应显示已收录子项进度，并避免把不完整清单判定为官方项目完成。

## 多类别身份与重叠关系

- 同一实际地点可以同时出现在多个类别中，例如世界遗产、全国重点文保单位和 A 级景区。
- 各类别身份分别保存点卯状态；点亮一个类别不会静默修改另一个类别。
- 点亮一个类别后，如果存在同一实际地点的其他类别记录，可以询问是否一并点亮；该询问属于独立设置项，默认每次询问。
- 资料栏可以同时展示同一地点的多个身份，但顶部主要按钮只操作当前所选类别。
- 一个项目与另一个项目只有部分重叠时，不把一个项目的点亮状态直接传播给另一个项目。资料栏提供关联入口，列出重叠或包含的实际地点，供使用者分别选择。
- 复杂关系第一版采用显式关联数据；不通过名称相同、距离接近或类别相似自动推断身份关系。

## 设置与撤销

设置页面至少提供三项独立询问策略：

1. 总项目与组成子项：每次询问、自动全部点亮、仅记录实际选择的子项。
2. 同一地点的其他类别：每次询问、自动关联点亮、不联动其他类别。
3. 点位与行政区：每次询问、自动点亮、不联动行政区。

- 第一版默认三项均为“每次询问”。
- 一次点卯及其被确认的关联修改应作为一个可撤销操作。
- 取消关联确认时，保留点位本身已经确认的修改，并且不修改未勾选的关联目标。

## 第一版范围

第一版需要完成：

- 独立点位点卯入口和页面路由。
- 沿用区域地图视野的点位图层和类别切换。
- 点位聚合或缩放展开的基础行为。
- 可关闭、可缩回的右侧资料栏。
- 固定在资料栏上部的点亮按钮和可滚动详情区。
- 点位、子项、跨类别身份和行政区关联确认流程。
- 三项关联询问设置、默认值保存和单次操作撤销。
- 现有圆点作为临时点位标识；图标、图片、资料字段和视觉主题保留后续调整空间。

## 暂不在第一版内的内容

- 重新设计或替换所有点位图标。
- 补齐缺失的地理坐标、边界和图片资料。
- 自动从外部数据源推断地点身份、跨区关系或项目重叠关系。
- 一次性建立完整的世界遗产、文保单位、景区和其他类别的重叠关系库。
- 改写现有区域点卯的计分规则、旅行状态等级或地图底图来源。

## 变更控制

### 2026-10-06 追加确认：暂缓拆分旧共用记录

现有目录有 40 组跨类别身份共用同一记录。使用者选择“暂不改变旧记录，先完成页面和其他交互”。第一版保留这些记录及原有读写规则；独立点位页展示其现状，但暂不开放会静默修改其他类别的操作。分类独立存档和相应迁移留待后续确认。已有独立记录的显式身份关系仍采用上述询问策略。

总项目的派生状态仅用于新点位页，旧总项目记录保留，不自动转换为子项到访。新页面所有关联选择完成后统一提交；跳过关联仍提交已明确选择的点位修改。

### 2026-10-06 追加授权：独立模块的整体 UI 改造

使用者明确允许非常大的 UI 变动，不要求与旧站点风格对齐。点位页采用独立页面框架、控件和资料栏设计；保留切换回区域点卯的接口。地图引擎和数据可以复用，旧站点的导航、表单和工具栏视觉无需沿用。此授权仅扩大 UI 改造范围，以上记录规则及暂缓拆分旧共用记录的决定继续适用。

以下变更在实施前需要重新确认：

- 改变地图仍为页面主视图，或改变资料栏可以收起的要求。
- 让一个类别的点卯静默传播到另一个类别。
- 让总项目重新拥有独立手动点卯状态。
- 改变三项询问设置的含义、默认值或保存范围。
- 修改现有区域点卯的记录、计分、行政区派生或地图视野规则。
- 引入新的用户可见流程、批量操作、账号同步或外部数据写入。

如果实现中发现必须超出上述范围才能保证数据安全、存档兼容或现有区域点卯不被破坏，应先说明原因、影响的文件和替代方案，再继续修改。

### 2026-10-06 确认：字体、字号与后续 UI 调研

使用者认可独立模块的整体方向，要求继续逐项讨论所有 UI 元素，并根据回答实时修改真实页面。每轮围绕两到三项具体的视觉或操作选择提问，用可理解的尺寸、位置和表现说明差别，不要求使用者提供设计术语。新流程与记录规则仍按上述变更控制执行。

已确认的文字规范：

- 全部使用黑体；地名和按钮采用较轻字重，整体保持轻盈。
- 地名标题 32px，正文和按钮 16px，辅助信息 14px；允许资料栏增加滚动量，不通过缩小文字压缩信息。
- 所有有用信息接近正文的深色，包括行政区、点亮状态、缺坐标提示、地图标注、选择控件和记录偏好说明；仅纯装饰文字使用淡色。
- 地图控件、目录、详情、确认页与记录偏好均执行同一规范，不只调整标题。

后续按字体与颜色、地图探索控件、顶栏、资料栏与主要按钮、资料字段与目录、确认界面、地图标识、响应反馈与手机布局逐轮调研。是否采用 UI 库属于实现选择，以已确认的外观与操作要求为依据；不让 UI 库反过来决定页面风格。

地图周围控件的追加选择：

- 顶栏压到约 56px，保留“方舆”“点位点卯”“记录偏好”和“区域点卯”，去掉英文装饰。
- 左上角默认是类似右侧设置的一个小按钮；光标移上后展开横向的范围与类别控件，移开后收起。展开后范围和类别各自有选择菜单。地点目录使用独立按钮，不与类别控件合成一个面板。触屏通过点击开关，键盘也可以选择。本条取代前一轮“范围、类别、目录始终横向可见”的理解。
- 资料顶部的点亮按钮保留深色填充，宽度随文字长度确定，放在标题下方靠左，留出更多空白；仍固定在可滚动正文之外。关联确认的按钮布局后续单独讨论。
- 资料栏仍停靠右侧，可以拖动左边缘调整宽度；地图随栏宽伸缩，保持中心和缩放，也可以随时关闭。支持键盘调整，手机布局另行讨论。长行政区名称的显示方式暂留后续讨论。
- 资料栏顶部类别与地名之间留白收紧到约 18px；字段仍按名称和值两列对齐，行距稍紧，使用少量分隔线。
- 探索、目录、选择菜单保留柔和圆角，去掉大部分阴影。小按钮悬停和展开时位置保持不变，只让背景略变暗。
- 右上设置入口仅打开点位关联偏好：总项目与组成地点、同地点其他类别、所在行政区划。三项规则沿用已确认含义。
- 点位模块始终使用现有行政区底图，不提供在线地图开关、底图类型、密钥或相关配置；不修改区域页的底图设置。
- 选中点位时自动高亮其明确关联的当前地图行政区，跨区点位展示所有明确关联范围。高亮仅为查看资料，不自动点亮行政区、不改变地图中心和缩放；点卯关联确认时以实际勾选范围预览。
- 不提供单独“显示选中范围”操作。地图图片导出属于另一个功能，不放入设置，本轮不增加新的导出入口。
- 图例作为右下角独立入口，点击展开与收起。来源保留地图图层已有的右下角来源显示，删除设置中的重复内容；简化地图下使用同一位置的来源入口补足显示。
- 记录偏好不放在顶栏，也不使用右侧资料栏；只通过地图上的设置按钮打开覆盖地图的浮层。浮层保留三项点卯关联策略，说明文字使用短标题和短句，避免设置页面堆叠。
- 打开设置保留当前点位资料栏，不改变地图视野或资料栏宽度。设置标题为“记录偏好”，说明缩为“点亮后的关联方式”；三项短标题为“组成地点、其他类别、所在行政区”。选择项压缩为“每次询问、全部点亮／同时点亮、仅实际选择／不关联”，保存的策略值与原有规则不变。

### 2026-10-06 确认：弱化底图与行政区填色预览

- 点位页行政区只保留边界，不显示区域记录状态的底色，不响应区域点击、悬停提示或选择光标；拖动与缩放继续可用。区域点卯页保持原有行为。
- 在底图细节上覆盖一层半透明浅色蒙版，点位、点位名称、控件及选中范围位于蒙版上方。
- 选中点位后，明确关联行政区使用半透明色块填充，不再加粗或改变选中边界颜色；本轮先采用纯色，斜线条纹保留为后续视觉讨论项。
- 填色使用对应行政区的真实多边形。显示省级边界时，县级关联仍只填县级范围；不以包围盒或上级行政区替代。跨区关联均可显示，父子范围同时出现时避免叠加加深；同一区划在不同地图层级重复出现时只填一次。
- 保留多边形内环和多片区域：其他行政区的内嵌飞地不随周围行政区填色，所选行政区自身的离散飞地一起填色，不连接片区间的空白。
- 没有选中点位时，不因继承区域页的当前行政区而显示预览填色。填色仅用于查看或确认，不修改记录或移动地图。
- 图例相应显示点位状态和当前预览范围，不再展示在点位页中已隐藏的行政区记录底色。
