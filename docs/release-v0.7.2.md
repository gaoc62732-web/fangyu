# 方舆旅游手册 0.7.2 更新说明

发布日期：2026-10-04。应用、工作区包及构建版本统一为 **0.7.2**，目录版本为 `2026-10-04.1`。

## 本次修订

- 中国手册成为主导航的独立首项；日本和韩国继续位于“东亚”专题菜单。
- 新加坡、马来西亚、文莱专题保留西沙、南沙离散岛礁不可悬停、不可点选的行为，移除专题专属提示文字；由各专题现有地区面生成更醒目的国界线，保持瓦片地图与 Canvas 备用地图一致。
- “丞相祠堂”的陕西目标由眉县改为岐山县，说明更新为五丈原诸葛亮庙；已有地区到访记录不被自动改写。
- 要素列表按名称合并跨市县的同一机场，显示涉及政区，勾选时同步对应条目；世界遗产等跨地区条目沿用原有合并方式。
- 中国县区的“途径”和“飞跃”状态向所属地级、省级地图显示汇总；原有常驻／短居向直属地级的汇总保留。汇总只在读取时计算，不覆盖省市手动记录，也不改变成就中对飞跃、途径的未到达判定。

## 数据边界与升级

- 当前合并版本接入自定义 OSM Liberty 底图及 2026-10-03/04 获取的中国 OSM 精细行政边界，映射到 3,237 个目录地区；文登区、汉南区及 7 个历史地区保留原几何，具体覆盖与例外见 `data/boundaries/china-osm/coverage.json`。此更新与上游 0.7.2 的功能修订一并保留。
- 公共目录与边界通过 GitHub Release 数据包同步，代码仓库只保存清单、配置与来源报告；当前数据清单版本为 `osm-20261009-v073`。获取方式见[获取开发数据](data-download.md)。
- 保留原有地区及条目 ID，旧记录仍可在新目录中使用；个人记录仅保存在用户自己的浏览器或自行导出的备份中，公开仓库不含个人存档。
- 旧版 0.7.1 更新说明及代码仍在 Git 历史中。回退前先导出当前记录；旧版本不保证读取新版本导出的存档。
- 地图仅供旅行记录参考，不用于法律、测绘或边界认定。来源及许可详见 [数据说明](data-notices.md)。

## 验证

当前合并版本通过目录引用检查、前后端生产构建、地图资源、县区状态汇总及“丞相祠堂”目标专项检查。浏览器验收覆盖精细边界、底图切换与故障回退、记录保留、跨地区机场合并、省市汇总显示、专题导航和地图，以及手机与桌面布局；当前数据包恢复与 637 个文件的 SHA-256 校验通过。

全工作区类型检查未通过：现有前端工作区范围类型、`footprintPng` 导出、悬停类型及测试依赖等问题仍待处理。生产 API、真实账号和线上数据库迁移未列入本次验收。
