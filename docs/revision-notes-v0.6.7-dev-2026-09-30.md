# 方舆新版地图 v0.6.7-dev 修订说明

修订日期：2026-09-30

目标分支：`dev/new`

原版备份：`backup/dev-new-before-v0.6.7-20260930`（原提交 `270220d`）

## 本轮范围

本轮在 Vue、TypeScript 与独立目录数据构成的重构版上调整界面和交互。目录、行政区划图形、成就目标及后端数据库结构没有在本轮修改。版本由 `0.6.0-dev` 递增至 `0.6.7-dev`；中间的本地调整一并收录于此次推送。

## 地图与政区浏览

- 中国手册增加省级、市州盟级、县区级显示层级切换；不同层级使用不同的边线宽度。点击县区后的自动缩放更克制，滚轮缩放速度和最大倍率也收紧。
- 地图面积扩大，右栏改为以选中政区为中心显示下辖地区及内容项目；下辖地区过多时可展开全部。内容项目按“山川与景区”“历史与文化”“交通行旅”等组分级展开，上方的内容类别选择移到地图下方。
- 地图重新提供悬浮提示，显示政区名称、到访状态或项目名称与类别。世界地图悬浮提示上行显示中文名，下行显示目录中的英文名。
- 日本、韩国及世界地图不绘制项目点位。选中台湾省及其下辖政区时，中国地图也不绘制交通项目蓝点；台湾项目仍可在右栏查看和填写。离开台湾视图后，中国其他地区的点位开关继续有效。
- 地图工具栏下方固定显示边界说明：“边界与行政区划图形仅供旅行记录参考，不代表权威或现行的地理边界与行政区划；具体情况请以主管部门公布的资料为准。”日间和夜间模式均有醒目样式。

## 导航、列表与成就

- 顶部导航收拢为“中国”“世界”“其他国家”“点卯计算器”“要素列表”“旅行成就”“工具”；“其他国家”下可进入日本和韩国专题，鼠标离开菜单时自动收起。新增日夜模式快捷按钮及页面版本号。
- 要素列表可按所属范围逐级选择政区，再按类别、到访情况和关键字筛选；日本铁路项目区分 JR 与其他铁道。跨政区的同名项目按适用范围合并展示所属政区，批量勾选会同步更新组内记录。
- 成就页面按中国政区、历史人文、政区趣味、山河线路、要素数量、国际成就分入口；中国政区进一步区分数量、行遍、满贯、制霸，国际成就按主题浏览。数量级别显示名称与下一目标，徽章详情可查看目标并分批展开；详情关闭按钮保持在可见位置。
- 点卯计算器恢复为独立的顶部入口，按当前记录计算省级、地级、县级卯分与比例，支持按卯分、卯县数、卯县比例升降排序及导出 CSV。居住、短居、到达计分，途经、飞跃不计分。

## 本机迁移与资料保护

- 本机开发服务增加旧版记录的迁移入口：仅从 `127.0.0.1` 服务中的 `.local-records/record.json` 读取，经存档结构校验后导入。目录已加入 `.gitignore`，个人记录文件不会随代码提交。
- 保留应用内正常的 JSON 导入与备份流程。此次推送只包含程序、说明文档和原有公开目录文件的未改动版本，不包含本机到访存档或浏览器记录。

## 验证与边界

- 全工作区 TypeScript 类型检查、生产构建及目录引用检查通过；在本机浏览器确认边界说明出现、选择台湾省后点位开关消失且右栏项目继续显示。构建仍提示导入页面的单个 JavaScript 分包超过 500 kB，需要后续性能优化。
- 本轮未做数据库、服务端联调或完整的跨浏览器回归。重构版仍为开发分支，不能据此视为正式上线版本。
- GitHub 的原版以独立备份分支保留；新版推送到 `dev/new`，不覆盖 `main`。如需比对或回退，可直接比较这两个分支。
