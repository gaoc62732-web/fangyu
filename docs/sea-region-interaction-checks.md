# 西沙、南沙行政区交互检查

越南、马来西亚、新加坡、文莱专题共用精确行政区命中规则，马新文组合页切换国家后同样适用。规则只覆盖研究快照中已核验的 328 个离散多边形：不改变原始边界、标签、地点点位或个人记录，也不将整个海域矩形作为屏蔽范围。边界填色仍可显示；这些多边形上的行政区悬浮和点击不应产生提示、选择或下钻。

证据与源文件 SHA 位于 `data/extensions/research/south-china-sea-interaction-mask.json`。运行时包只保留精确环、保留陆地组件的 bounds、源 SHA 与许可证；不包含研究测试点。更新原始地图后必须重新审核组件，源 SHA 不一致时生成和回归检查均会失败。

执行纯规则、真实 Canvas 共用命中方法与源文件回归：

```powershell
node --import ./node_modules/.pnpm/tsx@4.23.15/node_modules/tsx/dist/loader.mjs scripts/verify-sea-region-interaction.mts
```

结果保存至 `data/generated/sea-region-interaction/pure-results.json`。测试包含 2,889 组地理点在四个 scope 下的 11,556 次断言、五个具名岛礁、孔洞与边界、MVT 量化边缘、保留大陆片以及地点点位优先；法国和中国等其他 scope 没有这项规则。测试不冒充浏览器指针事件验收。

浏览器检查由统一预览发布后执行：

1. 在越南专题平移并缩放至具名测试文件中的永兴岛、赵述岛、珊瑚岛和南威岛，分别移动鼠标、点击、触屏轻点。不得出现外国行政区 tooltip、指针手形或地区选择变化；先在普通地区悬浮，再移入被排除岛礁，旧提示必须清除。
2. 检查庆和、岘港本土与近岸岛、马来西亚半岛、北婆罗洲、新加坡、文莱、海南和泰国正常行为。马新文组合页逐国切换后重复检查，其他 scope 的行为应保持原样。
3. 在一次性浏览器上下文阻断 `.pbf` 请求，等待 `data-map-mode="canvas"`，重复普通陆地和被排除分片的鼠标及触控检查；也可在地图错误后使用公开的“使用简化地图”按钮。不要清除用户浏览器存储。
4. 地点点位保持可选，列表和个人记录保持不变。地图底图切换、缩放及返回操作不能解除行政区交互规则。

MVT 简化轮廓超出原始环时，仅对实际命中的离散片进行相交核验；如果该片可能触及保留陆地的 bounds，则不扩大排除。此保守处理避免将整省主片或正常海岸误禁，不能用于推断主权、海域范围或测绘精度。
