# 球场体验记录

足球场的“到访”“参观球场”“现场观赛”分别保存，互不推断。参观和观赛不会自动勾选到访或所属地区；取消到访（包括清除到访操作）也不会清除参观、观赛记录。共享同一 `recordId` 的球场条目共享体验状态。旧存档已有的到访保持原样，不补造参观或观赛记录。

空存档和仅含旧记录的存档仍使用格式版本 1；首次设置球场体验后，存档升级为版本 2，记录新增可选的 `stadiumExperiences` 数组（`tour`、`match`）。本版本支持导入格式 1 和 2，格式 1 不允许夹带该字段；旧客户端不支持格式 2，不能读取包含新体验的导出文件。撤销首次体验操作可以恢复此前的格式 1 状态。导入仍执行目录版本白名单、项目 ID 与所属类别校验。
