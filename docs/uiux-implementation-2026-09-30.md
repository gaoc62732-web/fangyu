# 方舆 UI/UX 实现与验收记录（2026-09-30）

## 本轮范围

在现有 Vue / Pinia / RecordSnapshot 架构上实现“保留手册逻辑，完善地图探索”。没有修改数据库、后端记录接口、实体 ID 或领域层到访规则。

参考基线为 `v0.5.0 / 3decac6`。本轮实现的是新界面及交互；下面明确区分自动验证、图片实物验证和仍需浏览器完成的验收。

## 已实现的使用路径

| 区域      | 当前行为                                                                                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 应用框架  | 地图、成就、记录管理三个主入口；外观与帮助为辅助入口。保存状态、错误恢复、撤销始终可达。输入框内保留原生撤销。                                                          |
| 地区手册  | 地区选择器、层级路径、六级状态；默认包含下辖条目。具体类别显示已标记/收录数，少量展开、长清单主动展开后虚拟渲染。无内容类别统一收起，标题旁可直接选择类别添加个人项目。 |
| 主题探索  | 从全局入口或分类标题旁箭头进入当前中国/世界/国家专题的全域目录，保留原地图视野。地区预览提供“仅看此地区”和“查看地区手册”。                                              |
| 详情      | 地图点和清单名称在同一侧栏打开详情，不改搜索词或筛选范围。组成项目逐项标记；归属不明确时选定本次地区。名称与备注明确保存/取消，离开时检查未保存内容。                   |
| 上下文    | 地图/宽幅清单共用搜索、类别、地区、记录筛选。返回详情保持列表；当前会话内最多保留 40 个目录上下文的滚动与展开状态。每个地理范围的最后状态保存到浏览器。                 |
| 搜索      | 查询名称、别名、代码、线路、组成项目与所属地区；地区匹配独立显示。拖动地图不改变目录，显式“搜索此区域”仅筛选真实坐标，退出恢复原范围。                                  |
| 连续记录  | 未标记筛选下，本次刚勾选的行保留在原位，直到主动改变查询。组成项目使用中间态；取消主项按现有规则同时清除其组成项目标记，政区记录保留。                                  |
| 批量      | 独立选择模式；应用前显示项目数、政区影响和歧义；整次应用对应一次撤销。                                                                                                  |
| 地图      | MapLibre 图层、静态 MVT、聚合、符号碰撞、按缩放显示名称；重合项目侧栏选择。行政区状态、选择、悬停通过 feature-state 更新。                                              |
| 探索/足迹 | 同一份记录与浏览上下文，切换显示强度。类别清单筛选独立于行政区填色；专题填色明确表示单个类别有无标记。                                                                  |
| 成就      | 九个系列、十九级称号、原篆字字体、旗帜区域配色和国际五系列配色；系列内省份/搜索/状态筛选，虚拟卡片，按需取得目标，目标每页 60 项。返回地图后可回原系列。                |
| 卯分      | 独立子视图，显示分省数量、比例、排序、统计口径和 CSV 导出。                                                                                                             |
| 导入      | 五步流程，匹配/歧义/未匹配/无变化分组；完整替换与合并区别显示；备份与修订检查；等待持久化成功后再显示完成。解析可取消，输入保留。                                       |
| 存档      | 紧凑列表、自动/手动区分、改名、下载、恢复和删除影响提示。恢复与清空前备份，失败不报告成功。                                                                             |
| 图片      | 独立于联网底图生成 PNG；当前地区/全域、1920/3840px、真实坐标已标记点；先预览再下载，含标题、图例、统计、日期与来源说明。                                                |
| 外观      | 暖白、低饱和绿、赭色与深色模式；桌面单侧栏、窄窗换行布局、可见焦点、原生模态对话框和状态提示。                                                                          |

浏览状态不进入记录撤销历史。共享条目及政区带入仍调用原领域规则；取消项目不会清除政区，降低政区不会清除项目。保存冲突保留本地记录，可导出备份、重试保存；重试仍使用原预期修订号，不覆盖他人更新。

## 地图资源与启动

`npm run dev:web`、`npm run build` 与 `npm test` 会先执行 `scripts/prepare-web.mjs`。首次生成可能需要几十秒，之后按源文件哈希跳过未变化资源。

生成目录为 `data/generated/web`（不提交）：

- `bootstrap.json`：轻量地区与类别。
- `catalog-manifest.json`、`catalog.json.gz`：完整目录，按内容版本缓存。完整加载和记录校验完成前不开放记录操作。
- `map-manifest.json`：范围、各层级瓦片地址、稳定地区 ID 对应的定位边界。
- `tiles/{scope}/{level}/{z}/{x}/{y}.pbf`：国家、省、市、县分层静态 MVT。普通地图按需请求。
- `maps/{scope}.json`：显示用简化几何，供 Canvas 降级与独立图片导出。
- `geometry/{scope}.geo.json`：原精度空间匹配源，仅地理导入和明确进入旧地图对照时加载。
- `fonts/fangyu-seal.woff2`：原版篆字字体。

MVT 和 PNG 不改变空间匹配源。D3 绘图需要的多边形方向调整只作用于显示副本，防止把多边形补集当成行政区填满画布。

普通构建无须 Git 历史；篆字字体与展示元数据已随源代码保存。`scripts/extract-legacy-presentation.mjs` 仅用于维护时重新提取参考提交的等级称号、配色和字体，不在正常启动链路中执行。

开发对照入口为 `/#/map-legacy`，帮助页可达。它明确按旧方式加载原精度边界，**不用于日常浏览性能验收**；真实画面验收完成后可删除。

## 天地图配置及尚待验证事项

在 `apps/web/.env` 中设置：

```dotenv
VITE_APP_MODE=demo
VITE_API_BASE_URL=/api/v1
VITE_TIANDITU_KEY=
VITE_PAGES_BASE=/
```

`VITE_TIANDITU_KEY` 是公开浏览器端服务密钥，应在供应商控制台限制实际使用域名。不要填入服务端秘密。配置后重启前端/重新构建；为空时不请求天地图，使用自身边界。没有自动切换收费服务。

当前接入天地图 `vec_w` 和 `cva_w` Web Mercator 瓦片，保留署名。服务错误隐藏在线图层，保留边界；初始化超时会尝试 Canvas 简化地图，并提供重试。Canvas 降级保留地区查看、真实坐标定位与记录，但不提供视野查询。

**本环境没有已配置的正式服务密钥，也没有可用浏览器连接，以下没有完成实网验收：**

1. 中国大陆网络访问、不同运营商下加载和超时行为。
2. 中文标注覆盖、地名碰撞和边界/坐标叠合实测。
3. 当前免费额度、域名白名单、CORS 与服务条款。
4. 发布域名下署名、密钥限制与实际瓦片加载。

需要在正式密钥和目标部署域名上完成以上检查，再把联网底图标为已验收。在线底图截图导出继续暂缓；当前 PNG 完全独立于底图。

部署到子路径时将 `VITE_PAGES_BASE` 设为 `/fangyu/`。Vite 配置同时支持环境文件和命令行环境变量；使用哈希路由。Worker、瓦片、字体和目录均通过应用 base 解析，瓦片占位符保留为字面量 `{z}/{x}/{y}`。

## 验证方式与边界

自动回归使用真实目录和现有领域规则，持久化和 WebGL 浏览器部分用测试替身，**不会改动用户记录**：

- 北京/东城下辖范围、仅本级、全国主题及 245 条中国世界遗产目录。
- 点位详情、归属选择、连续标记、返回位置与整次撤销。
- 地图/清单上下文、视野查询、跨日期变更线以及退出恢复。
- 旧查询晚到时丢弃结果，长清单 DOM 有界。
- 九系列与原版展示元数据、目标按需加载。
- 导入取消、保存等待、保存失败不重复应用。
- 地图未就绪时的点位更新与地区定位、聚合放大、重合候选及 WebGL 初始化失败后的简化几何路径（地图引擎使用测试替身）。
- 生成的每类 MVT 可解码并携带稳定 regionId；MapLibre 样式验证与子路径占位符。
- 足迹 PNG 实际编码、解码、尺寸、着色区域与图像检查（1920px 中国/世界、3840px 中国）。测试图片写入 `data/generated/verification`，不含个人记录。

运行：

```sh
npm run typecheck
npm test
npm run build
npm run catalog:check
```

本次验证结果：全项目类型检查、前后端生产构建、目录引用检查、29 项自动回归均通过。已实际解码并检查中国/世界 PNG。以 `/fangyu/` 启动生产预览后，`scripts/verify-web-assets.mjs` 对 28 个资源请求逐一核对生产文件，包含两类 Worker、字体、压缩目录及所有瓦片层级的样本；31912 条目录完整解码。测试同时覆盖服务器已经自动解压 gzip 的情况，防止重复解压。

MapLibre 与导入页面的包仍较大（各约 300KB gzip），目前按路由加载；生产构建保留包体积提示，真实首屏和输入延迟仍需浏览器测量。

可在启动生产预览后运行 `node scripts/verify-web-assets.mjs http://127.0.0.1:5178/fangyu/` 复查资源。

热查询测试把同机预热后的检索限制在 300ms 内；这是查询内核指标，不等同于真实浏览器的端到端输入延迟。大型导入中依赖 DOMParser 的部分保留在主线程；取消会在异步处理边界生效，不声称能中断已经执行中的同步解析。

## 保持暂缓的事项

未补坐标，不按同名合并世界遗产，不把行政区中心点冒充项目坐标。中国手册 245 条世界遗产仍可清单记录；世界目录有 60 条中国遗产带坐标，未建立自动关联。
