# 越南专题展示范围修正

本次追加用户要求：西沙、南沙对应几何不再出现在越南专题的抽象地图中。此前 `sea-region-interaction-checks.md` 记录的仅交互屏蔽已被本次展示过滤补充；其他三个国家继续采用原有精确命中策略。

`scripts/prepare-web.mjs` 在生成展示数据前，按已冻结掩膜及原始几何索引精确移除 328 个远海组件，保留 34 个行政区、2,375 个组件。矢量瓦片、简化 Canvas 数据、全图及行政区视野边界使用同一组保留几何。因此平移、缩放、返回全图和 PNG 导出都不会重新引入被排除的组件；这不只是缩小初始视野。

原始边界文件、供数据分析使用的原始几何副本、目录及用户记录未改。其他国家展示文件内容保持一致。每次生成先检查掩膜、来源 SHA 和组件身份；不使用粗略矩形裁剪。旧越南瓦片仅在已验证的生成目录内清理，避免遗留旧瓦片。

验证命令：

```powershell
node --import ./node_modules/.pnpm/tsx@4.23.15/node_modules/tsx/dist/loader.mjs scripts/verify-vietnam-display.mts
node scripts/verify-vietnam-display-ui.mjs
```

静态验证已通过：328 个排除点不在简化数据及全部 9 个生成瓦片中；2375 个保留组件、所有展示 bounds、其他国家数据、法国下钻缩放配置和原始数据一致性均通过。机器结果：`data/generated/vietnam-display-verification.json`。

浏览器验证通过，证据为 `data/generated/vietnam-display-ui/summary.json`、截图索引为同目录 `README.md`。1440/390宽度 × 瓦片/Canvas四种组合均通过：8次初始及返回全图、8个真实PNG、8次远海局部空背景及无命中、8次正常近岸交互，未捕获页面异常。PNG逐一检查328个排除点，其中285点在图内为精确海面背景、43点在视窗外；远海局部另以140×140像素区域核验。全部9个HTTP瓦片与已解码的生成产物哈希一致。

瓦片首轮逐像素断言失败来自右下角来源署名控件覆盖，并非边界残留；复测只排除实际控件DOM矩形遮挡的样本，其他点仍按精确颜色检查，原始诊断保留。浏览器使用隔离合成环境，不读取个人浏览器数据。用户提供的 Library 图片因官方下载辅助程序在 Windows 缺少 `os.setxattr` 而未能本地物化；未将图片元数据说明冒充为像素检查，本次验收依据实际应用截图和展示几何。
