# 山西
* 阳泉市城区：娘店社区

* **阳泉市郊区**：托管后被分割成两部分。城区整建制托管了郊区义井镇的全部14个行政村，矿区托管了郊区平坦镇的18个行政村。
* 长治潞城区：安林寺村
