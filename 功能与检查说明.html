功能与检查说明

本版范围

中国手册含 3246 个政区条目和 14 类内容；省级 34 个显示单元，市州盟级 392 个显示单元，其中 389 个有独立边界。392 的口径含直辖市、省直辖县及港澳台，成就“满贯·全国”仍仅统计 333 个地级政区。县界沿用已有工程矢量数据，没有由截图描摹。

新星、白杨、草湖暂缺独立市界，仍可从卡片记录。台湾采用已有 20 个县市单元；金门、马祖沿用手册福建所属行。世界含国家和地区目录、机场及世界遗产。来源与范围可在地图下方查看。

数据清空范围

已清除中国、台湾和世界的个人勾选、旅行状态及原始到访字段；初始 JSON 为空。内嵌 Excel 导出模板也清除了到访标记、蓝色个人标注和旧统计缓存。未附带历史个人清单、截图、差异表或个人记录文件。

审核版使用独立数据指纹与浏览器存储，不会读入个人工作版记录。审核期间的新记录只保存在审核人员的浏览器中；请导出 JSON 才能交回或跨电脑备份。审核 JSON 用于此审核版本，不直接导入个人工作版。

操作要点

顶部切换中国手册、世界、要素列表与成就。中国手册可选择省、市州盟、县三个地图层级，每一级都能下载 PNG。省市卡片支持搜索、状态编辑和定位；地图悬浮显示政区名。

居住、短居和到达计入到达；途经、飞跃、未到达不计。勾选内容项会补记所属政区及上级到达，保留已有居住或短居。手工修改政区状态不会批量改动下辖内容。

批量导入先预览匹配，再应用；重名站需手动选择，不认识的条目留待核查。旧站名可通过别名匹配。导入测试文件为公开名录选取的 100 个条目，仅测试功能，不代表任何人的行程。

KML 可一次选择多个本机文件，按点位和轨迹合并匹配中国县区并去重；预设导入等级可修改并在本浏览器记忆，预览后仍可逐县调整或统一套用。只提升原有较低等级，应用前可预览与导出含逐文件来源、跳过原因的核对清单。照片位置导入可在本机离线读取 JPEG、HEIC／HEIF、TIFF 与带 eXIf 的 PNG，按内嵌 GPS 匹配中国县区。一次最多 2000 张、单张最多 80 MB；无 GPS、县界外、边界重叠或坐标基准待核的项目单列，不自动写入。默认途经，应用前逐县确认；已有更高旅行等级不会被覆盖。照片原文件不会上传或写入存档，核对 CSV 含精确坐标，请自行保管。手机相册后加的非内嵌地点及视频暂不支持。

导出 CSV 目前限中国手册范围。Excel 同时包含原手册和新增要素。导出存档 JSON 保留记录，成就载入后重新计算。丝绸之路、万里茶道按地级单元展示已核子集，不代表全线完成；其他线路仍有核查工作在进行。

检查结果及限制

自动化检查覆盖地图启动、三个层级、反向定位、六种状态、成就计数、PNG、100 个车站 TXT 导入、存档清空撤销、JSON、CSV 及 Excel XML 结构。另核查审核包初始到访和成就为零、原工作版存储隔离、内嵌导出模板无个人标记及 ZIP 文件完整性。

照片解析已用合成 JPEG、HEIC、PNG、TIFF 样本检查坐标、县区匹配、等级保护和 CSV；实际手机厂商文件仍请人工抽样验收。浏览器功能采用模拟 DOM 与画布检查；未代替人工在桌面 Edge、Chrome 和 Excel 中打开验收。成就旗帜采用《说文解字》小篆节选字库，当前全部旗帜名称均有字形；另有已说明的异体映射及现代部件拼合设计。
